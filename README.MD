# EasyDash Plugin for WooCommerce

Welcome to the EasyDash Plugin for WooCommerce! This plugin provides a comprehensive order dashboard and additional useful features to help WooCommerce store owners manage and monitor their orders more efficiently from the WordPress admin panel.

With EasyDash, you can get detailed insights into your order data, track progress, and enhance your store's overall order management process.

## Features

- **Order Dashboard**: A user-friendly and intuitive dashboard for viewing order details, including statuses, customer information, and more.
- **Order Filters**: Easily filter orders by status, date, payment method, etc.
- **Sales Insights**: View real-time sales data and key performance indicators (KPIs) for your store.
- **Quick Order Actions**: Manage orders with ease by performing actions such as marking orders as shipped, processing, or completed directly from the dashboard.
- **Order Summary**: Get a detailed summary of order activity, including total revenue, number of orders, and top-selling products.
- **Customizable Widgets**: Add, remove, or rearrange widgets on the dashboard to suit your needs.
- **Export Orders**: Export order data to CSV for further analysis or reporting.

## Installation

### Prerequisites
- A WordPress website with WooCommerce installed.
- Administrative access to the WordPress admin panel.

### Steps
1. **Download the Plugin**:
   - Obtain the EasyDash Plugin from the official GitHub repository or download it from the WordPress plugin marketplace.

2. **Install the Plugin**:
   - Log in to your WordPress admin panel.
   - Navigate to **Plugins > Add New**.
   - Click on **Upload Plugin** and select the `easydash.zip` file.
   - Click **Install Now** and then activate the plugin.

3. **Configure the Plugin**:
   - Go to the **EasyDash settings page** in your WordPress admin panel under **WooCommerce > Settings > EasyDash**.
   - Configure the dashboard settings, including choosing which widgets to display and their layout.
   - Set up notification preferences to be alerted about important order changes.

4. **Test the Dashboard**:
   - Visit the **EasyDash Dashboard** page to see the order summary, sales insights, and other features in action.
   - Verify that the order data is displayed accurately and updated in real time.

## Usage

### View the Order Dashboard
Once the plugin is configured, you will see the **EasyDash Dashboard** in your WordPress admin panel. The dashboard will display:
- **Order Status Summary**: The total number of orders categorized by status (e.g., Pending, Processing, Completed).
- **Sales Overview**: Key sales metrics such as total revenue, average order value, and top-selling products.
- **Recent Orders**: A list of the latest orders with their status, customer information, and payment method.

### Filter Orders
Use the order filter options to view specific orders based on:
- Order status
- Date range
- Payment method
- Customer details
- Shipping method

### Quick Actions
From the dashboard, you can take quick actions on orders, such as:
- Marking orders as shipped, processed, or completed.
- Viewing customer details and order history.
- Generating invoices or packing slips.

### Customize the Dashboard
You can customize the EasyDash dashboard by:
- Adding or removing widgets.
- Rearranging the widget layout.
- Adjusting the data displayed in each widget.

### Export Orders
You can export your order data by:
- Clicking the **Export Orders** button on the dashboard.
- Selecting the date range and filter options for the orders you want to export.
- Downloading the order data in CSV format for further analysis.
